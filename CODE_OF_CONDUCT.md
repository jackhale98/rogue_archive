# Code of conduct

Rogue Archive is a friendly project about games people love. Participants are expected to:

- Be respectful and assume good faith. Critique work, not people.
- Welcome newcomers to the codebase and to the genre.
- Respect the authors and communities of the games we host: credit them, follow their licenses and contribution rules, and report bugs to them kindly.

Harassment, discrimination, personal attacks and sharing others' private information are not acceptable in issues, pull requests, discussions or any project space.

Maintainers may edit or remove content and restrict participation to enforce this. Report concerns privately to the maintainers through GitHub (e.g. a private security advisory if no other private channel is listed). Reports are handled confidentially.
