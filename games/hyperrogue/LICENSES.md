# HyperRogue port — license and provenance report

This report covers every file the HyperRogue port distributes from the public site. It is an engineering record, not legal advice. Re-check it whenever the pinned upstream version changes.

**Summary:** everything shipped has a documented redistribution basis. HyperRogue's code is **GPL-2.0-or-later** (every source file's header; `COPYING` is the GPL version 2 text). The port compiles upstream's own web version, which draws everything with code and a built-in font table, so no image, sound or font files are shipped. The port's own files use the same licence. Music and sounds (some under CC BY-SA 4.0) are in the upstream repository but are **not** used or shipped.

## Obligations and how they are met

- **GPL source availability:** the deployed site links to this repository, which pins the exact upstream commit and contains the port's own source and build scripts; anyone can rebuild the shipped files (`scripts/build.sh`).
- **Licence text and notices:** `licenses/HyperRogue-COPYING.txt` is shipped inside the runtime directory; the game prints its copyright and licence notice at start-up, unchanged.
- **DejaVu fonts licence:** its text is shipped with the runtime.
- **zlib licence:** requires that its notice not be removed from source distributions; the pinned source is fetched unmodified.

## Provenance

HyperRogue is developed by Zeno Rogue (Eryk Kopczyński) with contributors since 2011. The pinned tag `v13.1p` is upstream's latest release at the time of porting; its commit is the head of `master` on that date (2026-11-07).
