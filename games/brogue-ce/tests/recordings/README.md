# Recording fixtures

Saves and recordings replayed by `scripts/test-engine.sh` in both native desktop Brogue CE (same commit) and our WASM engine. The two must produce identical output and replay to the end of the file.

| File | Provenance |
|---|---|
| `browser-explore-115-turns.broguesave` | Made by Rogue Archive in the browser build (Brogue CE 1.15.1): a new game with ~115 turns of auto-explore and movement including combat, saved with `S` and exported with *Export saves*. Generated by this project; no third-party content. Distributed under the port's AGPL-3.0-or-later. |

Add fixtures that exercise more systems (stairs, items, allies, death) as they are produced. A finished `.broguerec` (from a death or victory) must exit cleanly.
