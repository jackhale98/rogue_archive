This report covers every file the Brogue CE port distributes from the public site. It is an engineering record, not legal advice. Re-check it whenever the pinned upstream version changes.

**Summary:** everything shipped has a documented redistribution basis. The game build is distributed under **AGPL-3.0-or-later**, and its complete corresponding source (upstream at the pinned commit plus this directory and the build scripts) is published in this repository.

## Obligations and how they are met

- **AGPL-3.0 source availability:** the site links to this repository from the game page and the About page. The repository contains the exact build recipe, the pinned upstream revision (verified by commit hash at build time), the platform file and the adapter. The game page shows the pinned version, commit and build ID.
- **AGPL network clause:** the game runs on the player's device; nothing is executed server-side. Source is offered regardless.
- **License texts:** `licenses/BrogueCE-LICENSE.txt` and `licenses/tiles-LICENSE.txt` are shipped inside the runtime directory next to the binary.
- **CC BY-SA 4.0 attribution and share-alike:** attribution is on the game page and the About page; the sheet is unmodified; the derived cover image is offered under CC BY-SA 4.0.

## Contribution policy

Brogue CE's `CONTRIBUTING.md` does not restrict how contributions are authored as of `v1.15.1`. This port needs **no** upstream changes, and none have been proposed upstream. Re-read the policy before proposing any.
