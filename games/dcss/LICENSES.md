# DCSS port — license and provenance report

This report covers every file the DCSS port distributes from the public site. It is an engineering record, not legal advice. Re-check it whenever the pinned upstream version changes.

**Summary:** everything shipped has a documented redistribution basis. The game build is distributed under **GPL-2.0-or-later** (upstream's license); the bundled pieces under other licenses are GPL-compatible, as upstream's `LICENSE` lists. The complete corresponding source (upstream at the pinned commit, its pinned submodules, this directory and the build scripts) is published in this repository.

## Obligations and how they are met

- **GPL-2.0 source availability:** the game page and the About page link to this repository, which holds the exact build recipe, the pinned upstream revision (verified by commit hash at build time, submodules pinned by upstream), the platform layer, the shims, the host page and the adapter. The game page shows the pinned version, commit and build ID.
- **License texts:** `licenses/DCSS-LICENSE.txt` (upstream `LICENSE`), the texts from upstream's `docs/license/` (CC0, LGPL, Lua, PCRE, libpng, worley) and `licenses/DejaVu-fonts-LICENSE.txt` are shipped inside the runtime directory.
- **Credits:** DCSS's `CREDITS.txt` is part of the game data and shown by the game's own help; the game page credits the DCSS team.

## Security

The upstream WebTiles client is designed to render only what the game sends it. Here the game runs locally in the player's own browser, so the client only ever renders the player's own game: there is no other player, server or network input. The client runs in a same-origin frame under its own Content-Security-Policy (`script-src 'self'`, no inline scripts, no remote connections).

## Contribution policy

DCSS's `crawl-ref/docs/develop/contribution-process.md` does not address how contributions are authored as of `0.34.1`. This port needs **no** upstream changes, and none have been proposed upstream. Re-read the policy before proposing any.
