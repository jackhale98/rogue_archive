# Sil-Q port — license and provenance report

This report covers every file the Sil-Q port distributes from the public site. It is an engineering record, not legal advice. Re-check it whenever the pinned upstream version changes.

**Summary:** everything shipped has a documented redistribution basis. Sil-Q is offered by its authors under **either GPL-2.0 or the Angband licence**; Rogue Archive distributes it under **GPL-2.0-only**. The complete corresponding source (upstream at the pinned commit, this directory and the build scripts) is published in this repository. Nothing under the licence's exceptions (graphics, sounds, fonts) is shipped.

## Why GPL-2.0-only

Upstream's `LICENSE.md` offers "the GNU General Public License as published by the Free Software Foundation, version 2, or the Angband licence". It names version 2 and no later version, so the GPL option is GPL-2.0-only. The Angband licence restricts distribution to "educational, research, and not for profit purposes"; the GPL option has no such restriction and is the one used here.

## Obligations and how they are met

- **GPL-2.0 source availability:** the game page and the About page link to this repository, which holds the exact build recipe, the pinned upstream revision (verified by commit hash at build time), the display module and the adapter. The game page shows the pinned version, commit and build ID.
- **License text:** `licenses/Sil-Q-LICENSE.md` (upstream `LICENSE.md`, which includes the full GPL-2.0 text) is shipped inside the runtime directory.
- **Notices:** Sil-Q shows its own credits and version (`V` in game).

## Contribution policy

Sil-Q's README invites pull requests for new platforms and does not address how contributions are authored. This port needs **no** upstream changes, and none have been proposed upstream. Re-read the project's guidance before proposing any.
